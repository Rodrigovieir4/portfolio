# Estética do portfólio — material de referência

Gerado em 18/11/2026 no Higgsfield (GPT Image 2.6, 2K) e capturado do Instagram.
O Rodrigo gostou de partes das três rodadas e quer misturar. Nada aqui é a
versão final: pessoas e textos das imagens geradas são provisórios.

Aqui ficam as cópias leves, versionadas no repositório. As originais em 2K
estão fora do git, em `D:/workspace/Claude outputs/portfolio-estetica/`.

`paletas.html` compara as paletas monocromáticas (escolhida: 7, Grafite + vinho).
`tipografia.html` é a rodada 1 de fontes (dela ficou só Anton nos números).
`tipografia-titulos.html` é a rodada 2, só para os títulos.

`esboco.html` é o esqueleto interativo do site: abra no navegador (precisa de
internet, carrega o React de um CDN).
